# data/

Place the Kaggle Loan Prediction dataset here before running `train_model.py`.

## Dataset Source

**Kaggle — Loan Prediction Problem Dataset**
https://www.kaggle.com/datasets/altruistdelhite04/loan-prediction-problem-dataset

## Instructions

1. Download the dataset from Kaggle (requires free account)
2. Save the CSV file in this folder as **`loan_data.csv`**
3. Then run: `python train_model.py`

## Accepted filenames

The app checks for these filenames in order:
- `loan_data.csv`  ← preferred
- `dataset.csv`
- `loan_data_set.csv`

If none are found, the app falls back to a built-in sample dataset automatically.
